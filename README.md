# Curso Backend con Node.js, Express y TypeScript

Repositorio de aprendizaje y práctica del desarrollo **backend con Node.js**, siguiendo principalmente el contenido de [JSCamp](https://www.jscamp.dev/backend-con-nodejs-y-express/ficheros-y-sistema-de-modulos).

El objetivo del repositorio es documentar de forma práctica el aprendizaje de las herramientas y conceptos fundamentales para desarrollar aplicaciones backend modernas con **Node.js, Express y TypeScript**.

## Tecnologías

* JavaScript
* Node.js
* Express
* TypeScript
* npm
* Git / GitHub

El aprendizaje está organizado de forma progresiva, comenzando por los fundamentos de Node.js y avanzando hacia la construcción de APIs backend.

## Prácticas

Además del contenido teórico, el repositorio contiene ejercicios propios para reforzar los conceptos aprendidos.

Algunas de las prácticas realizadas incluyen:

* Información del sistema mediante `process` y `path`.
* Uso de argumentos mediante `process.argv`.
* Configuración mediante variables de entorno.
* Creación y manipulación de archivos con `fs/promises`.
* Separación de lógica mediante módulos.
* Aplicaciones CLI.
* Manejo de errores.
* Operaciones asíncronas con `async/await`.

Los ejercicios se irán ampliando a medida que avance con el curso

## Objetivo del repositorio

Este repositorio tiene como objetivo construir una base sólida para el desarrollo backend.

La progresión buscada es:

```text
JavaScript
    ↓
Node.js
    ↓
   HTTP
    ↓
Express
    ↓
REST APIs
    ↓
CRUD / MVC
    ↓
Testing
    ↓
TypeScript
```

La intención es comprender primero los fundamentos y posteriormente aplicarlos en proyectos backend más completos.

## Curso de referencia

El contenido principal se basa en el módulo **Backend con Node.js y Express** de JSCamp, que incluye Node.js, Express, REST APIs, CRUD, MVC y otros conceptos relacionados con el desarrollo backend.

También se incorporarán ejercicios y prácticas adicionales para profundizar los conceptos y adaptarlos a mis intereses de desarrollo backend.
